# Quantum Natural Gradient

This repository provides a professional implementation of Quantum Natural Gradient (QNG) and related quantum machine learning techniques using PennyLane.

## Installation

Prerequisites: 

1. Clone the repository:
   ```bash
   git clone https://github.com/rssonnm/quantum_natural_gradient.git
   cd quantum_natural_gradient
   ```

2. Install the package in editable mode:
   ```bash
   pip install -e .
   ```
